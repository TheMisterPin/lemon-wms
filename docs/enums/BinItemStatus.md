# BinItemStatus

## Purpose
Represents current availability state of stock in a bin.

|---|---|
| `AVAILABLE` | Allowed `BinItemStatus` value used by business rules. |
| `RESERVED` | Allowed `BinItemStatus` value used by business rules. |
