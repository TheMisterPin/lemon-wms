# SerialStatus

## Purpose
Represents lifecycle state of a serial number.

## Values
| Value | Meaning |
|---|---|
| `IN_STOCK` | Allowed `SerialStatus` value used by business rules. |
| `SHIPPED` | Allowed `SerialStatus` value used by business rules. |
| `RETURNED` | Allowed `SerialStatus` value used by business rules. |
| `SCRAPPED` | Allowed `SerialStatus` value used by business rules. |
